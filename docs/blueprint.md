# **App Name**: Comando Rápido

## Core Features:

- Dynamic Command Generation: Generate server administration commands dynamically based on user-selected actions (e.g., give items, change weather, teleport), players, and items/values.
- Multilingual Interface: Toggle all application labels and text between 'English' and 'Español' using a radio button in the sidebar.
- Parameterized Selection UI: Utilize dropdown menus in the main area to select actions, players, and specific items or numerical values, allowing for clear command parameter input.
- AI-Powered Command Parameter Suggestions: An AI tool that suggests valid parameters and their correct syntax based on the selected action and server context, assisting in the accurate construction of complex commands.
- Command Output and Copy: Display the generated server command in a distinct code block area, providing a button for easy one-click copying to the clipboard.

## Style Guidelines:

- Primary interactive color: A vibrant cyan, #00B4D8 (HSL: 195, 100%, 43%), reflecting a sense of technical precision and efficiency.
- Complementary background color: A very light, desaturated cyan, #F7F9FA (HSL: 195, 15%, 98%), used for structured sections and cards to subtly distinguish elements while maintaining a clean look.
- Accent color: A dynamic blue, #1A71EB (HSL: 225, 80%, 50%), providing a clear visual contrast for highlights and interactive elements without straying into forbidden hues.
- General UI and headline font: 'Space Grotesk' (sans-serif) for its modern, slightly tech-inspired, and legible appearance, suitable for headlines and short textual components.
- Command display font: 'Source Code Pro' (monospace sans-serif) for its optimal readability when presenting computer code or terminal commands, ensuring clarity and distinction from other text.
- Employ a set of clear, concise line-style icons to represent various actions (e.g., give, weather, teleport), players, and settings, enhancing usability without visual clutter.
- A responsive two-column layout featuring a fixed-width sidebar for language selection and global controls, and a main content area dedicated to command parameter input and output, ensuring intuitive navigation and workflow.
- Implement subtle, instant feedback animations on parameter selections and command generation, such as a quick fade or slight scale effect, to acknowledge user interaction without causing delays.
